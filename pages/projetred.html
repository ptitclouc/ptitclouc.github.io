Projet RED

Contexte du projet

Le projet RED a été réalisé dans le cadre de ma formation, en collaboration avec d'autres étudiants. Ce projet nous a permis de travailler en équipe et de mettre en pratique ce que l'on avait appris. Nous avons dû nous organiser, répartir les différentes tâches et communiquer afin de faire avancer le projet ensemble.

Présentation et technologies

Au cours de ce projet, j'ai participé au développement et à la réalisation des différentes fonctionnalités avec mon équipe. Cette expérience m'a permis de développer mes compétences en programmation, mais aussi de mieux comprendre l'organisation d'un projet réalisé à plusieurs. Nous avons également utilisé Git et GitHub pour gérer les différentes versions du projet et partager notre travail.

Technologies utilisées

  • Visual Studio Code
  • Go
  • Git et GitHub

Ce que ce projet m'a apporté

La réalisation du projet RED m'a permis de progresser dans le travail en équipe et dans l'organisation d'un projet informatique. J'ai appris à mieux collaborer avec d'autres personnes, à partager mon code et à participer à un projet commun. Le dépôt contenant le code source du projet est disponible sur GitHub.
