Go Reloaded

Contexte du projet

Le projet Go Reloaded a été réalisé dans le cadre de ma formation afin de mettre en pratique mes connaissances en programmation avec le langage Go. L'objectif de ce projet était de développer mes capacités d'analyse et de résolution de problèmes en créant un programme fonctionnel.

Présentation et technologies

Ce projet m'a permis de travailler avec le langage Go et de mieux comprendre l'importance d'un code organisé et structuré. J'ai travaillé sur la logique du programme ainsi que sur les différentes fonctionnalités nécessaires à son bon fonctionnement. Git et GitHub ont également été utilisés pour sauvegarder, gérer et partager le code du projet.

Technologies utilisées

  • Visual Studio Code
  • Go
  • Git et GitHub

Ce que ce projet m'a apporté

Grâce à Go Reloaded, j'ai pu renforcer mes compétences en programmation et en algorithmique. Ce projet m'a appris à analyser un problème, à chercher des solutions et à organiser mon code de manière plus efficace. Il m'a également permis de progresser dans l'utilisation de Git et de GitHub pour gérer un projet de développement.
